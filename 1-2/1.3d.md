# Лабораторна робота 1. Складність алгоритмів. Час виконання

## Завдання для самостійної роботи 1.3 d)

### Умова

Визначити час виконання фрагмента програми:

```python
1  i = 0
2  while i < n:
3      j = 0
4      while j < i * i:
5          k += 1
6          j += 1
7      i += 1
```

---

### Теоретичні засади (за підручником А. П. Креневича «Алгоритми і структури даних», 2021, с. 13–15)

Часом виконання програми $T(n)$ називається кількість елементарних операцій, які виконує комп'ютер під час роботи програми (у спрощеній моделі комп'ютера вважається, що кожна елементарна операція триває однаковий час $\tau = 1$).

До елементарних операцій належать:
* **Звернення до об’єкта в пам’яті** (змінної або літералу/константи) — 1 операція.
* **Присвоєння** (`=`) — 1 операція.
* **Елементарні арифметичні операції** (`+`, `-`, `*`, `/`, `//`, `%`) — 1 операція.
* **Операції порівняння** (`>`, `<`, `>=`, `<=`, `==`, `!=`) — 1 операція.

**Зауваження щодо операцій `+=`:**
Згідно з підручником (с. 14), операції виду `+=` і подібні виконуються за **4 операції**, оскільки їх слід інтерпретувати як повний запис (наприклад, `j = j + 1` або `i = i + 1`):
1. звернення до змінної в пам'яті (1);
2. звернення до літерала `1` в пам'яті (1);
3. арифметична операція (1);
4. присвоєння (1).

---

### Порядковий аналіз виконання

Розглянемо випадок для невід'ємного цілого $n \ge 0$:

1. **Рядок 1 (`i = 0`):**
   * Звернення до літерала `0` (1) + присвоєння змінній `i` (1) = **2 операції** (виконується 1 раз).
   * Час: $2$.

2. **Рядок 2 (`while i < n:`):**
   * Кожна перевірка: звернення до `i` (1) + звернення до `n` (1) + порівняння `<` (1) = **3 операції**.
   * Змінна $i$ приймає значення $0, 1, 2, \dots, n-1$ (на яких умова істинна — $n$ разів), і при $i = n$ умова стає хибною (1 раз). Всього **$n + 1$ перевірок**.
   * Час: $3(n + 1)$.

3. **Рядок 3 (`j = 0`):**
   * Звернення до `0` (1) + присвоєння `j` (1) = **2 операції**.
   * Виконується на кожній з $n$ ітерацій зовнішнього циклу.
   * Час: $2n$.

4. **Рядок 4 (`while j < i * i:`):**
   * Кожна перевірка виразу `j < i * i`:
     * звернення до `j` (1);
     * звернення до першого множника `i` (1);
     * звернення до другого множника `i` (1);
     * операція множення `*` (1);
     * операція порівняння `<` (1).
     * Разом на одну перевірку: $1 + 1 + 1 + 1 + 1 = \mathbf{5}$ операцій.
   * Для фіксованого значення $i$ змінна $j$ змінюється від $0$ до $i^2 - 1$ ($i^2$ разів умова повертає `True`), а при $j = i^2$ повертає `False` (1 раз). Тобто для поточного $i$ виконується $i^2 + 1$ перевірок.
   * За всіма ітераціями зовнішнього циклу ($i = 0, 1, \dots, n-1$) кількість перевірок дорівнює:
     $$\sum_{i=0}^{n-1} (i^2 + 1) = \sum_{i=0}^{n-1} i^2 + n$$
   * Час: $5 \sum_{i=0}^{n-1} i^2 + 5n$.

5. **Рядок 5 (`k += 1`):**
   * Інтерпретується як `k = k + 1`: доступ до `k` (1) + доступ до `1` (1) + додавання `+` (1) + присвоєння `=` (1) = **4 операції**.
   * Для поточного $i$ виконується $i^2$ разів.
   * Загальний час: $4 \sum_{i=0}^{n-1} i^2$.

6. **Рядок 6 (`j += 1`):**
   * Інтерпретується як `j = j + 1`: доступ до `j` (1) + доступ до `1` (1) + додавання `+` (1) + присвоєння `=` (1) = **4 операції**.
   * Загальний час: $4 \sum_{i=0}^{n-1} i^2$.

7. **Рядок 7 (`i += 1`):**
   * Інтерпретується як `i = i + 1`: доступ до `i` (1) + доступ до `1` (1) + додавання `+` (1) + присвоєння `=` (1) = **4 операції**.
   * Виконується на кожній з $n$ ітерацій зовнішнього циклу.
   * Час: $4n$.

### Таблиця підрахунку часу виконання

| Рядок | Інструкція | Операцій на 1 крок | Кількість виконань | Загальний час |
| :---: | :--- | :---: | :---: | :--- |
| **1** | `i = 0` | $1 + 1 = 2$ | $1$ | $2$ |
| **2** | `while i < n:` | $1 + 1 + 1 = 3$ | $n + 1$ | $3(n + 1)$ |
| **3** | `j = 0` | $1 + 1 = 2$ | $n$ | $2n$ |
| **4** | `while j < i * i:` | $1 + 1 + 1 + 1 + 1 = 5$ | $\sum_{i=0}^{n-1} (i^2 + 1)$ | $5 \sum_{i=0}^{n-1} i^2 + 5n$ |
| **5** | `k += 1` | $1 + 1 + 1 + 1 = 4$ | $\sum_{i=0}^{n-1} i^2$ | $4 \sum_{i=0}^{n-1} i^2$ |
| **6** | `j += 1` | $1 + 1 + 1 + 1 = 4$ | $\sum_{i=0}^{n-1} i^2$ | $4 \sum_{i=0}^{n-1} i^2$ |
| **7** | `i += 1` | $1 + 1 + 1 + 1 = 4$ | $n$ | $4n$ |

### Обчислення суми квадратів

Відомо, що сума квадратів перших $(n-1)$ невід'ємних цілих чисел дорівнює:
$$\sum_{i=0}^{n-1} i^2 = \frac{(n-1)n(2n-1)}{6} = \frac{2n^3 - 3n^2 + n}{6}$$

---

### Підсумковий час виконання $T(n)$

Сумуємо всі складові:
$$T(n) = 2 + 3(n + 1) + 2n + 5n + 4n + (5 + 4 + 4) \sum_{i=0}^{n-1} i^2$$
$$T(n) = 13 \sum_{i=0}^{n-1} i^2 + 14n + 5$$

Підставляємо вираз для суми квадратів:
$$T(n) = 13 \cdot \frac{2n^3 - 3n^2 + n}{6} + 14n + 5$$
$$T(n) = \frac{13}{3}n^3 - \frac{13}{2}n^2 + \frac{13}{6}n + 14n + 5$$
$$T(n) = \frac{13}{3}n^3 - \frac{13}{2}n^2 + \frac{97}{6}n + 5$$

* **Для $n \ge 0$:**
  $$T(n) = \frac{13}{3}n^3 - \frac{13}{2}n^2 + \frac{97}{6}n + 5$$
  *(наприклад: $T(0) = 5$, $T(1) = 19$, $T(2) = 46$)*.

* **Для $n \le 0$:**
  Цикли не виконуються:
  $$T(n) = 2 + 3 = 5$$

**Асимптотична оцінка складності:** $\Theta(n^3)$ або $O(n^3)$ (кубічна складність / кубічний час виконання).
