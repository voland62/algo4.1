# Лабораторна робота 2. Складність алгоритмів. Асимптотична оцінка

## Завдання для самостійної роботи 2.10

### Умова

Визначте асимптотичну оцінку виконання функції у найгіршому випадку в термінах $O$–«великого» для функції:

```python
def f(n):
    sum = 0
    for i in range(1, n + 1):
        sum = sum + i
    return sum
```

**Питання:**
1. Що є результатом виконання наведеної функції для заданого натурального числа $n$?
2. Чи можна оптимізувати цю функцію, покращивши її асимптотичну оцінку?

---

### Теоретичні засади (за підручником А. П. Креневича «Алгоритми і структури даних», 2021, с. 24–26)

Згідно з **Теоремою 2.2.8 (Цикл `for`)**:
> Найгірший час виконання алгоритму, що містить цикл `for`:
> ```python
> for i in range(S1):
>     S2
> ```
> має асимптотичну складність:
> $$O(\max\{T_1(n) \times (I(n) + 1), \, T_2(n) \times I(n)\})$$
> де $T_1(n), T_2(n)$ — час виконання інструкцій $S_1, S_2$, а $I(n)$ — кількість ітерацій циклу в найгіршому випадку.

Згідно з **Теоремою 2.2.6 (Послідовна композиція)**:
> Складність послідовності блоків дорівнює максимуму їхніх складностей: $O(\max\{T_1(n), \dots, T_m(n)\})$.

---

### 1. Асимптотичний аналіз функції $f(n)$

1. **Рядок `sum = 0`:**
   * Проста операція присвоєння. Час виконання не залежить від $n$, тобто становить $O(1)$.

2. **Цикл `for i in range(1, n + 1):`**
   * Кількість ітерацій циклу для натурального $n \ge 1$: $I(n) = n$.
   * Тіло циклу (`sum = sum + i`) містить операції звернення до змінних, додавання та присвоєння, кожна з яких виконується за сталий час $O(1)$.
   * Відтак час виконання циклу:
     $$T_{\text{loop}}(n) = n \times O(1) = O(n)$$

3. **Рядок `return sum`:**
   * Повернення результату виконується за сталий час $O(1)$.

4. **Загальна складність:**
   $$T(n) = O(1) + O(n) + O(1) = O(n)$$

**Відповідь:** Асимптотична оцінка виконання функції $f(n)$ у найгіршому випадку становить **$O(n)$** (лінійний час).

---

### 2. Результат виконання функції

Функція $f(n)$ здійснює послідовне додавання всіх цілих чисел від $1$ до $n$:

$$\text{sum} = \sum_{i=1}^n i = 1 + 2 + 3 + \dots + n$$

За формулою суми арифметичної прогресії:
$$\sum_{i=1}^n i = \frac{n(n + 1)}{2}$$

**Відповідь:** Результатом виконання функції для натурального числа $n$ є **сума перших $n$ натуральних чисел**, яка дорівнює:
$$\frac{n(n + 1)}{2}$$

---

### 3. Оптимізація та покращення асимптотичної оцінки

**Так, функцію можна оптимізувати.**

Замість ітеративного циклу з $n$ ітераціями можна застосувати формулу арифметичної прогресії безпосередньо:

```python
def f_optimized(n):
    return n * (n + 1) // 2
```

#### Оцінка оптимізованої функції:
* Обчислення виразу `n * (n + 1) // 2` вимагає 4 елементарних операцій:
  1. додавання `n + 1`;
  2. множення на `n`;
  3. цілочисельне ділення на `2`;
  4. повернення результату (`return`).
* Кількість операцій є фіксованою і абсолютно не залежить від значення $n$.

**Висновок:** Нова асимптотична оцінка становить **$O(1)$** (сталий час виконання). Складність покращено з лінійної $O(n)$ до сталої $O(1)$.
