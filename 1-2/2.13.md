# Лабораторна робота 2. Складність алгоритмів. Асимптотична оцінка

## Завдання для самостійної роботи 2.13 (пункти a, e, g)

### Умова

Знайдіть асимптотичний час виконання програми у явному вигляді, якщо для нього відоме рекурентне співвідношення:

* **a)**
  $$T(n) = \begin{cases} O(1), & n = 0; \\ T(n - 1) + O(1), & n \ge 1. \end{cases}$$

* **e)**
  $$T(n) = \begin{cases} O(1), & n = 0; \\ T(n - 1) + O(n), & n \ge 1. \end{cases}$$

* **g)**
  $$T(n) = \begin{cases} O(1), & n = 1; \\ aT(\lfloor n/a \rfloor) + O(1), & n \ge 2, \quad a \ge 2. \end{cases}$$

---

### Теоретичні засади (за підручником А. П. Креневича «Алгоритми і структури даних», 2021, с. 15–18, 24–26)

Для знаходження асимптотичного часу виконання рекурентних алгоритмів застосовується **метод розгортання рекурентності (метод ітерацій / підстановки)**:
1. Послідовно підставляємо значення $T$ з попередніх кроків у рекурентне рівняння.
2. Знаходимо загальний вигляд виразу після $k$ підстановок.
3. Визначаємо крок $k$, на якому досягається базова умова.
4. Оцінюємо отриману суму у термінах $O$–«великого» або $\Theta$–оцінки.

---

## Пункт a)

$$T(n) = \begin{cases} O(1), & n = 0; \\ T(n - 1) + O(1), & n \ge 1. \end{cases}$$

### Розгортання рекурентності:
Нехай $O(1) \le c_1$, а базове значення $T(0) = c_0$, де $c_0, c_1 > 0$ — сталі:
* **Крок 1:**
  $$T(n) = T(n - 1) + c_1$$
* **Крок 2:**
  $$T(n) = [T(n - 2) + c_1] + c_1 = T(n - 2) + 2c_1$$
* **Крок 3:**
  $$T(n) = [T(n - 3) + c_1] + 2c_1 = T(n - 3) + 3c_1$$
* **Крок $k$:**
  $$T(n) = T(n - k) + k \cdot c_1$$

### Умова зупинки:
Підстановка завершується, коли досягнуто базовий випадок:
$$n - k = 0 \iff k = n$$

Тоді:
$$T(n) = T(0) + n \cdot c_1 = c_0 + c_1 n$$

### Асимптотичний вигляд:
Оскільки старший член є лінійним:
$$T(n) = O(n) \quad (\text{або } \Theta(n))$$

## Пункт e)

$$T(n) = \begin{cases} O(1), & n = 0; \\ T(n - 1) + O(n), & n \ge 1. \end{cases}$$

### Розгортання рекурентності:
Нехай $O(n) \le c \cdot n$, а $T(0) = c_0$:
* **Крок 1:**
  $$T(n) = T(n - 1) + c \cdot n$$
* **Крок 2:**
  $$T(n) = [T(n - 2) + c(n - 1)] + cn = T(n - 2) + c(n - 1) + cn$$
* **Крок 3:**
  $$T(n) = T(n - 3) + c(n - 2) + c(n - 1) + cn$$
* **Крок $k$:**
  $$T(n) = T(n - k) + c \sum_{j=0}^{k-1} (n - j)$$

### Умова зупинки:
Базовий випадок досягається при $n - k = 0 \iff k = n$:
$$T(n) = T(0) + c \sum_{j=0}^{n-1} (n - j) = T(0) + c \sum_{i=1}^n i$$

Використовуючи формулу суми арифметичної прогресії $\sum_{i=1}^n i = \frac{n(n + 1)}{2}$:
$$T(n) = c_0 + c \cdot \frac{n(n + 1)}{2} = \frac{c}{2} n^2 + \frac{c}{2} n + c_0$$

### Асимптотичний вигляд:
Старший член має порядок $n^2$:
$$T(n) = O(n^2) \quad (\text{або } \Theta(n^2))$$

## Пункт g)

$$T(n) = \begin{cases} O(1), & n = 1; \\ aT(\lfloor n/a \rfloor) + O(1), & n \ge 2, \quad a \ge 2. \end{cases}$$

### Розгортання рекурентності:
Для спрощення розгортання спочатку розглянемо випадок, коли $n = a^k$ (точний степінь $a$, тобто $k = \log_a n$).
Нехай $O(1) \le c$, а $T(1) = c_0$:

* **Крок 1:**
  $$T(a^k) = a T(a^{k-1}) + c$$
* **Крок 2:**
  $$T(a^k) = a [a T(a^{k-2}) + c] + c = a^2 T(a^{k-2}) + ac + c$$
* **Крок 3:**
  $$T(a^k) = a^2 [a T(a^{k-3}) + c] + ac + c = a^3 T(a^{k-3}) + a^2 c + ac + c$$
* **Крок $j$:**
  $$T(a^k) = a^j T(a^{k-j}) + c \sum_{i=0}^{j-1} a^i$$

### Умова зупинки:
Базовий випадок досягається при $a^{k-j} = 1 \iff k - j = 0 \iff j = k$:
$$T(a^k) = a^k T(1) + c \sum_{i=0}^{k-1} a^i$$

Сума перших $k$ членів геометричної прогресії зі знаменником $a \ge 2$:
$$\sum_{i=0}^{k-1} a^i = \frac{a^k - 1}{a - 1}$$

Враховуючи, що $n = a^k$:
$$T(n) = n \cdot c_0 + c \cdot \frac{n - 1}{a - 1} = \left(c_0 + \frac{c}{a - 1}\right) n - \frac{c}{a - 1}$$

Для довільного $n$ при $a^k \le n < a^{k+1}$ маємо той самий лінійний порядок.  
*(Зокрема, за Основною теоремою про рекурентності (Master Theorem): $n^{\log_a a} = n^1 = n$. Оскільки вільний член $f(n) = O(1) = O(n^{1 - \varepsilon})$, маємо перший випадок теореми, звідки $T(n) = \Theta(n)$).*

### Асимптотичний вигляд:
$$T(n) = O(n) \quad (\text{або } \Theta(n))$$
