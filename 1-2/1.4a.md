# Лабораторна робота 1. Складність алгоритмів. Час виконання

## Завдання для самостійної роботи 1.4 a)

### Умова

Визначити час виконання програми у явному вигляді, якщо для нього відоме рекурентне співвідношення:

$$T(n) = \begin{cases} 1, & n \le a, \quad a > 0; \\ T(n - a) + 1, & n > a. \end{cases}$$

---

### Теоретичні засади (за підручником А. П. Креневича «Алгоритми і структури даних», 2021, с. 15–18)

Для знаходження явного вигляду функції часу виконання $T(n)$, заданої рекурентним співвідношенням, використовується **метод розгортання рекурентності (метод ітерацій / підстановки)**:
1. Послідовно підставляємо вираз для функції на попередніх кроках у вихідне рівняння.
2. Знаходимо закономірність для $k$-го кроку розгортання.
3. Визначаємо умову зупинки (досягнення базового випадку рекурентності).
4. Отримуємо явну формулу для $T(n)$ та перевіряємо її методом математичної індукції.

---

### Метод розгортання рекурентності

Для $n > a$ послідовно застосовуємо рекурентне правило $T(n) = T(n - a) + 1$:

* **Крок 1:**
  $$T(n) = T(n - a) + 1$$

* **Крок 2:**  
  Підставляємо $T(n - a) = T(n - 2a) + 1$:
  $$T(n) = [T(n - 2a) + 1] + 1 = T(n - 2a) + 2$$

* **Крок 3:**  
  Підставляємо $T(n - 2a) = T(n - 3a) + 1$:
  $$T(n) = [T(n - 3a) + 1] + 2 = T(n - 3a) + 3$$

* **Крок $k$:**  
  Узагальнюючи на довільний крок $k$, отримуємо:
  $$T(n) = T(n - ka) + k$$

---

### Визначення умови завершення підстановки

Підстановка завершується, коли аргумент досягає базового випадку, тобто:
$$n - ka \le a$$

Знайдемо найменше ціле число кроків $k$, при якому ця нерівність виконується:
$$n - ka \le a \iff ka \ge n - a \iff k \ge \frac{n}{a} - 1$$

Оскільки на попередньому кроці ($k - 1$) аргумент був ще строго більшим за $a$:
$$n - (k - 1)a > a \iff ka < n \iff k < \frac{n}{a}$$

Об'єднуючи ці умови:
$$k < \frac{n}{a} \le k + 1 \iff k = \left\lceil \frac{n}{a} \right\rceil - 1$$

Позначимо $n_0 = n - ka$. Оскільки $n_0 \le a$, за базовою умовою задачі маємо:
$$T(n_0) = 1$$

Підставляємо значення $k$ у формулу для $T(n)$:
$$T(n) = T(n_0) + k = 1 + \left(\left\lceil \frac{n}{a} \right\rceil - 1\right) = \left\lceil \frac{n}{a} \right\rceil$$

---

### Доведення методом математичної індукції

Доведемо, що для всіх $n > 0$ має місце формула $T(n) = \left\lceil \frac{n}{a} \right\rceil$:

1. **База індукції:**  
   Нехай $0 < n \le a$. Тоді $0 < \frac{n}{a} \le 1$, звідки $\left\lceil \frac{n}{a} \right\rceil = 1$. За умовою $T(n) = 1$. База виконується.

2. **Індукційний перехід:**  
   Припустимо, що формула правильна для деякого $n > 0$, тобто $T(n) = \left\lceil \frac{n}{a} \right\rceil$.  
   Розглянемо значення для $n + a$:
   $$T(n + a) = T((n + a) - a) + 1 = T(n) + 1 = \left\lceil \frac{n}{a} \right\rceil + 1 = \left\lceil \frac{n}{a} + 1 \right\rceil = \left\lceil \frac{n + a}{a} \right\rceil$$
   Індукційний перехід доведено.

---

### Підсумковий результат

* **У загальному вигляді для всіх $n > 0$:**
  $$T(n) = \left\lceil \frac{n}{a} \right\rceil$$
  *(Зокрема, якщо $n$ ділиться на $a$ націло: $T(n) = \frac{n}{a}$).*

* **Для $n \le a$:**
  $$T(n) = 1$$

**Асимптотична оцінка складності:** $\Theta(n)$ або $O(n)$ (лінійна складність за аргументом $n$).
