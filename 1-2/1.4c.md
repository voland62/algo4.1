# Лабораторна робота 1. Складність алгоритмів. Час виконання

## Завдання для самостійної роботи 1.4 c)

### Умова

Визначити час виконання програми у явному вигляді, якщо для нього відоме рекурентне співвідношення:

$$T(n) = \begin{cases} 1, & n = 1; \\ 2T(\lfloor n/2 \rfloor) + 1, & n \ge 2. \end{cases}$$

---

### Теоретичні засади (за підручником А. П. Креневича «Алгоритми і структури даних», 2021, с. 15–18)

Для розв'язання рекурентних співвідношень типу «розділяй і володарюй», де аргумент на кожному кроці ділиться на сталу величину, у підручнику використовується метод підстановки (розгортання рекурентності).

1. Спочатку розглядається випадок, коли $n$ є точним степенем двійки: $n = 2^k$ ($k \ge 0$).
2. Потім результат узагальнюється на довільне натуральне $n \ge 1$ за допомогою цілої частини двійкового логарифма $\lfloor \log_2 n \rfloor$.

---

### Частковий випадок: $n = 2^k$ ($k \ge 0$)

Нехай $n = 2^k$. Тоді $\lfloor n/2 \rfloor = 2^{k-1}$. Розгортаємо рекурентність:

* **Крок 1:**
  $$T(2^k) = 2T(2^{k-1}) + 1$$

* **Крок 2:**  
  Підставляємо $T(2^{k-1}) = 2T(2^{k-2}) + 1$:
  $$T(2^k) = 2[2T(2^{k-2}) + 1] + 1 = 2^2 T(2^{k-2}) + 2 + 1$$

* **Крок 3:**  
  Підставляємо $T(2^{k-2}) = 2T(2^{k-3}) + 1$:
  $$T(2^k) = 2^2 [2T(2^{k-3}) + 1] + 2 + 1 = 2^3 T(2^{k-3}) + 2^2 + 2^1 + 2^0$$

* **Крок $j$:**  
  Узагальнюючи на крок $j$:
  $$T(2^k) = 2^j T(2^{k-j}) + \sum_{i=0}^{j-1} 2^i$$

Підстановка завершується при досягненні базового випадку $2^{k-j} = 1 \iff k - j = 0 \iff j = k$:

$$T(2^k) = 2^k T(1) + \sum_{i=0}^{k-1} 2^i$$

Оскільки за умовою $T(1) = 1$, а сума геометричної прогресії $\sum_{i=0}^{k-1} 2^i = \frac{2^k - 1}{2 - 1} = 2^k - 1$:

$$T(2^k) = 2^k \cdot 1 + (2^k - 1) = 2 \cdot 2^k - 1$$

Оскільки $n = 2^k$, отримуємо:
$$T(n) = 2n - 1$$

---

### Загальний випадок: довільне натуральне $n \ge 1$

Для довільного натурального числа $n \ge 1$ існує єдине ціле число $k \ge 0$ таке, що:
$$2^k \le n < 2^{k+1}, \quad \text{де } k = \lfloor \log_2 n \rfloor$$

Послідовні значення функції для малих чисел:
* $n = 1$: $T(1) = 1 = 2^1 - 1$
* $n = 2$: $T(2) = 2T(1) + 1 = 3 = 2^2 - 1$
* $n = 3$: $T(3) = 2T(\lfloor 3/2 \rfloor) + 1 = 2T(1) + 1 = 3 = 2^2 - 1$
* $n = 4$: $T(4) = 2T(2) + 1 = 2 \cdot 3 + 1 = 7 = 2^3 - 1$
* $n = 5, 6, 7$: $T(n) = 2T(2 \text{ або } 3) + 1 = 2 \cdot 3 + 1 = 7 = 2^3 - 1$
* $n = 8 \dots 15$: $T(n) = 2T(4) + 1 = 2 \cdot 7 + 1 = 15 = 2^4 - 1$

Бачимо закономірність: для всіх $n \in [2^k, 2^{k+1} - 1]$ значення функції дорівнює:
$$T(n) = 2^{k+1} - 1 = 2^{\lfloor \log_2 n \rfloor + 1} - 1$$

---

### Доведення загальної формули за індукцією

Доведемо за математичною індукцією за довжиною двійкового запису $k = \lfloor \log_2 n \rfloor$:

1. **База ($k = 0$, тобто $n = 1$):**  
   $$T(1) = 2^{0+1} - 1 = 1$$  
   Співпадає з базовою умовою.

2. **Індукційний перехід:**  
   Припустимо, що твердження істинне для всіх чисел з інтервалу $[2^{k-1}, 2^k - 1]$, тобто якщо $2^{k-1} \le m < 2^k$, то $T(m) = 2^k - 1$.  
   Розглянемо число $n$ таке, що $2^k \le n < 2^{k+1}$ ($k \ge 1$).  
   Тоді для аргументу $\lfloor n/2 \rfloor$ маємо:
   $$2^{k-1} \le \left\lfloor \frac{n}{2} \right\rfloor < 2^k$$
   За індукційним припущенням:
   $$T\left(\left\lfloor \frac{n}{2} \right\rfloor\right) = 2^{(k-1)+1} - 1 = 2^k - 1$$
   Тоді за рекурентним співвідношенням:
   $$T(n) = 2 T\left(\left\lfloor \frac{n}{2} \right\rfloor\right) + 1 = 2(2^k - 1) + 1 = 2^{k+1} - 2 + 1 = 2^{k+1} - 1$$
   Індукційний перехід доведено для всіх $k \ge 0$.

---

### Підсумковий результат

Явний вигляд часу виконання програми для довільного натурального $n \ge 1$:

$$T(n) = 2^{\lfloor \log_2 n \rfloor + 1} - 1$$

* Якщо $n = 2^k$ (степінь двійки):
  $$T(n) = 2n - 1$$

### Асимптотична оцінка складності

Оскільки $2^{\lfloor \log_2 n \rfloor} \le n < 2^{\lfloor \log_2 n \rfloor + 1}$, маємо подвійну нерівність:
$$n \le 2^{\lfloor \log_2 n \rfloor + 1} \le 2n \implies n - 1 \le T(n) \le 2n - 1$$

Отже, функція $T(n)$ обмежена лінійними функціями знизу та зверху:
$$T(n) = \Theta(n) \text{ або } O(n) \text{ (лінійна складність)}.$$
