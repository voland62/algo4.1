# Лабораторна робота 1. Складність алгоритмів. Час виконання

## Завдання для самостійної роботи 1.3 b)

### Умова

Визначити час виконання фрагмента програми:

```python
1  i = n
2  while i > 1:
3      k += 1
4      i //= 2
```

---

### Теоретичні засади (за підручником А. П. Креневича «Алгоритми і структури даних», 2021, с. 13–15)

Часом виконання програми $T(n)$ називається кількість елементарних операцій, які виконує комп'ютер під час роботи програми (у спрощеній моделі комп'ютера вважається, що кожна елементарна операція триває однаковий час $\tau = 1$).

До елементарних операцій належать:
* **Звернення до об’єкта в пам’яті** (змінної або літералу/константи) — 1 операція.
* **Присвоєння** (`=`) — 1 операція.
* **Елементарні арифметичні операції** (`+`, `-`, `*`, `/`, `//`, `%`) — 1 операція.
* **Операції порівняння** (`>`, `<`, `>=`, `<=`, `==`, `!=`) — 1 операція.

**Зауваження щодо операцій `+=`, `//=`:**
Згідно з підручником (с. 14), операції виду `+=`, `//=` і подібні виконуються за **4 операції**, оскільки їх слід інтерпретувати як повний запис (наприклад, `k = k + 1` або `i = i // 2`):
1. звернення до змінної в пам'яті (1);
2. звернення до літерала (`1` чи `2`) в пам'яті (1);
3. арифметична операція (додавання чи цілочисельне ділення) (1);
4. присвоєння (1).

---

### Кількість ітерацій циклу

На кожній ітерації циклу значення змінної $i$ замінюється на цілу частину від ділення на $2$:
* Початкове значення: $i_0 = n$.
* Після 1-ї ітерації: $i_1 = \lfloor n / 2 \rfloor$.
* Після 2-ї ітерації: $i_2 = \lfloor n / 2^2 \rfloor$.
* ...
* Після $m$-ї ітерації: $i_m = \lfloor n / 2^m \rfloor$.

Цикл продовжує роботу доти, доки $i > 1$, і завершується, щойно $i \le 1$.
* Якщо $n \le 1$, умова `i > 1` хибна відразу, тіло циклу не виконується жодного разу ($m = 0$).
* Для цілого числа $n \ge 1$ циклічне ділення навпіл до значення $i \le 1$ вимагає рівно:
  $$m = \lfloor \log_2 n \rfloor \text{ ітерацій.}$$
  *(Зокрема, якщо $n = 2^k$ для деякого цілого $k \ge 0$, то кількість ітерацій дорівнює $m = k = \log_2 n$).*

---

### Порядковий аналіз виконання

Нехай $m = \lfloor \log_2 n \rfloor$ (кількість ітерацій циклу для $n \ge 1$):

1. **Рядок 1 (`i = n`):**
   * Звернення до значення `n` в пам’яті (1) + присвоєння змінній `i` (1) = **2 операції**.
   * Виконується **1 раз**.
   * Час: $2$.

2. **Рядок 2 (`while i > 1:`):**
   * Кожна перевірка умови: звернення до `i` (1) + звернення до числа `1` (1) + операція порівняння `>` (1) = **3 операції**.
   * Кількість перевірок: умова повертає `True` $m$ разів, і ще 1 раз повертає `False` при виході з циклу. Разом **$m + 1$ перевірок**.
   * Час: $3(m + 1) = 3(\lfloor \log_2 n \rfloor + 1)$.

3. **Рядок 3 (`k += 1`):**
   * Інтерпретується як `k = k + 1`: звернення до `k` (1) + звернення до числа `1` (1) + додавання `+` (1) + присвоєння `=` (1) = **4 операції**.
   * Тіло циклу виконується **$m$ разів**.
   * Час: $4m = 4\lfloor \log_2 n \rfloor$.

4. **Рядок 4 (`i //= 2`):**
   * Інтерпретується як `i = i // 2`: звернення до `i` (1) + звернення до числа `2` (1) + операція `//` (1) + присвоєння `=` (1) = **4 операції**.
   * Тіло циклу виконується **$m$ разів**.
   * Час: $4m = 4\lfloor \log_2 n \rfloor$.

---

### Таблиця підрахунку часу виконання

| Рядок | Інструкція | Кількість операцій на 1 виконання | Кількість виконань ($m = \lfloor \log_2 n \rfloor$) | Загальний час |
| :---: | :--- | :---: | :---: | :--- |
| **1** | `i = n` | $1 + 1 = 2$ | $1$ | $2$ |
| **2** | `while i > 1:` | $1 + 1 + 1 = 3$ | $m + 1$ | $3(m + 1)$ |
| **3** | `k += 1` | $1 + 1 + 1 + 1 = 4$ | $m$ | $4m$ |
| **4** | `i //= 2` | $1 + 1 + 1 + 1 = 4$ | $m$ | $4m$ |

---

### Підсумковий час виконання $T(n)$

Сумуємо операції за всіма рядками:

$$T(n) = 2 + 3(m + 1) + 4m + 4m = 2 + 3m + 3 + 8m = 11m + 5$$

Підставляючи $m = \lfloor \log_2 n \rfloor$:

* **Для $n \ge 1$:**  
  $$T(n) = 11 \lfloor \log_2 n \rfloor + 5$$
  *(Зокрема, якщо $n = 2^k$, то $T(n) = 11 \log_2 n + 5$)*.

* **Для $n \le 1$:**  
  Цикл не виконується ($m = 0$), умова перевіряється 1 раз:  
  $$T(n) = 2 + 3 = 5$$

**Асимптотична оцінка складності:** $\Theta(\log n)$ або $O(\log n)$ (логарифмічна складність / логарифмічний час виконання).
