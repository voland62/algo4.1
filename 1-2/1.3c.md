# Лабораторна робота 1. Складність алгоритмів. Час виконання

## Завдання для самостійної роботи 1.3 c)

### Умова

Визначити час виконання фрагмента програми:

```python
1  i = 0
2  while i < n:
3      j = 0
4      while j < n:
5          k += 1
6          j += 2
7      i += 2
```

---

### Теоретичні засади (за підручником А. П. Креневича «Алгоритми і структури даних», 2021, с. 13–15)

Часом виконання програми $T(n)$ називається кількість елементарних операцій, які виконує комп'ютер під час роботи програми (у спрощеній моделі комп'ютера вважається, що кожна елементарна операція триває однаковий час $\tau = 1$).

До елементарних операцій належать:
* **Звернення до об’єкта в пам’яті** (змінної або літералу/константи) — 1 операція.
* **Присвоєння** (`=`) — 1 операція.
* **Елементарні арифметичні операції** (`+`, `-`, `*`, `/`, `//`, `%`) — 1 операція.
* **Операції порівняння** (`>`, `<`, `>=`, `<=`, `==`, `!=`) — 1 операція.

**Зауваження щодо операцій `+=`:**
Згідно з підручником (с. 14), операції `+=`, `-=` і подібні виконуються за **4 операції**, оскільки їх слід інтерпретувати як повний запис (наприклад, `j = j + 2` або `i = i + 2`):
1. звернення до змінної в пам'яті (1);
2. звернення до літерала `2` в пам'яті (1);
3. арифметична операція додавання `+` (1);
4. присвоєння `=` (1).

### Аналіз кількості ітерацій циклів

Розглянемо випадок для невід'ємного цілого $n \ge 0$:

1. **Зовнішній цикл (змінна $i$):**
   * $i$ починається з $0$ і на кожному кроці збільшується на $2$ (`i += 2`).
   * Кількість ітерацій зовнішнього циклу дорівнює:
     $$m = \left\lceil \frac{n}{2} \right\rceil$$
   * Умова `while i < n:` перевіряється $m$ разів зі значенням `True` та 1 раз зі значенням `False` (вихід з циклу). Всього **$m + 1$ перевірок**.

2. **Внутрішній цикл (змінна $j$):**
   * На кожній ітерації зовнішнього циклу $j$ скидається в $0$ і збільшується на $2$ (`j += 2`), поки $j < n$.
   * Кількість ітерацій внутрішнього циклу не залежить від $i$ і на кожній ітерації зовнішнього циклу дорівнює:
     $$m = \left\lceil \frac{n}{2} \right\rceil$$
   * Умова `while j < n:` перевіряється **$m + 1$ разів** за один прохід зовнішнього циклу.

### Порядковий аналіз виконання

Нехай $m = \lceil n / 2 \rceil$:

1. **Рядок 1 (`i = 0`):**
   * Звернення до `0` (1) + присвоєння `i` (1) = **2 операції** (виконується 1 раз).
   * Час: $2$.

2. **Рядок 2 (`while i < n:`):**
   * Кожна перевірка: доступ до `i` (1) + доступ до `n` (1) + порівняння `<` (1) = **3 операції**.
   * Виконується $m + 1$ разів.
   * Час: $3(m + 1)$.

3. **Рядок 3 (`j = 0`):**
   * Доступ до `0` (1) + присвоєння `j` (1) = **2 операції**.
   * Виконується на кожній ітерації зовнішнього циклу ($m$ разів).
   * Час: $2m$.

4. **Рядок 4 (`while j < n:`):**
   * Кожна перевірка: доступ до `j` (1) + доступ до `n` (1) + порівняння `<` (1) = **3 операції**.
   * На одну ітерацію зовнішнього циклу перевіряється $m + 1$ разів.
   * Оскільки зовнішній цикл виконується $m$ разів, загальний час: $3(m + 1) \cdot m = 3m^2 + 3m$.

5. **Рядок 5 (`k += 1`):**
   * Інтерпретується як `k = k + 1`: доступ до `k` (1) + доступ до `1` (1) + додавання `+` (1) + присвоєння `=` (1) = **4 операції**.
   * Загальна кількість виконань: $m \cdot m = m^2$.
   * Час: $4m^2$.

6. **Рядок 6 (`j += 2`):**
   * Інтерпретується як `j = j + 2`: доступ до `j` (1) + доступ до `2` (1) + додавання `+` (1) + присвоєння `=` (1) = **4 операції**.
   * Загальна кількість виконань: $m \cdot m = m^2$.
   * Час: $4m^2$.

7. **Рядок 7 (`i += 2`):**
   * Інтерпретується як `i = i + 2`: доступ до `i` (1) + доступ до `2` (1) + додавання `+` (1) + присвоєння `=` (1) = **4 операції**.
   * Виконується на кожній ітерації зовнішнього циклу ($m$ разів).
   * Час: $4m$.

### Таблиця підрахунку часу виконання

| Рядок | Інструкція | Кількість операцій на 1 виконання | Кількість виконань ($m = \lceil n/2 \rceil$) | Загальний час |
| :---: | :--- | :---: | :---: | :--- |
| **1** | `i = 0` | $1 + 1 = 2$ | $1$ | $2$ |
| **2** | `while i < n:` | $1 + 1 + 1 = 3$ | $m + 1$ | $3(m + 1)$ |
| **3** | `j = 0` | $1 + 1 = 2$ | $m$ | $2m$ |
| **4** | `while j < n:` | $1 + 1 + 1 = 3$ | $m(m + 1)$ | $3m(m + 1)$ |
| **5** | `k += 1` | $1 + 1 + 1 + 1 = 4$ | $m^2$ | $4m^2$ |
| **6** | `j += 2` | $1 + 1 + 1 + 1 = 4$ | $m^2$ | $4m^2$ |
| **7** | `i += 2` | $1 + 1 + 1 + 1 = 4$ | $m$ | $4m$ |

### Підсумковий час виконання $T(n)$

Сумуємо час усіх рядків через $m = \lceil n/2 \rceil$:

$$T(n) = 2 + 3(m + 1) + 2m + 3m(m + 1) + 4m^2 + 4m^2 + 4m$$
$$T(n) = 2 + 3m + 3 + 2m + 3m^2 + 3m + 8m^2 + 4m = 11m^2 + 12m + 5$$

Підставимо значення для парного та непарного $n$:

* **Для парного $n = 2k \ge 0$** ($m = n/2$):
  $$T(n) = 11\left(\frac{n}{2}\right)^2 + 12\left(\frac{n}{2}\right) + 5 = \frac{11}{4}n^2 + 6n + 5$$

* **Для непарного $n = 2k + 1 \ge 1$** ($m = \frac{n+1}{2}$):
  $$T(n) = 11\left(\frac{n+1}{2}\right)^2 + 12\left(\frac{n+1}{2}\right) + 5 = \frac{11}{4}n^2 + \frac{23}{2}n + \frac{55}{4}$$

* **Для $n \le 0$:**
  Цикли не виконуються, перевірка `0 < n` дає `False`:
  $$T(n) = 2 + 3 = 5$$

**Асимптотична оцінка складності:** $\Theta(n^2)$ або $O(n^2)$ (квадратична складність).
