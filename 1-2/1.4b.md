# Лабораторна робота 1. Складність алгоритмів. Час виконання

## Завдання для самостійної роботи 1.4 b)

### Умова

Визначити час виконання програми у явному вигляді, якщо для нього відоме рекурентне співвідношення:

$$T(n) = \begin{cases} 1, & n = 0; \\ T(n - 1) + 2^n, & n \ge 1. \end{cases}$$

---

### Теоретичні засади (за підручником А. П. Креневича «Алгоритми і структури даних», 2021, с. 15–18)

Для знаходження явного вигляду функції часу виконання $T(n)$ скористаємося **методом розгортання рекурентності (методом ітерацій / підстановки)** з наступним підсумовуванням членів послідовності.

---

### Метод розгортання рекурентності

Для довільного цілого $n \ge 1$ послідовно підставляємо значення функції з попередніх кроків:

* **Крок 1:**
  $$T(n) = T(n - 1) + 2^n$$

* **Крок 2:**  
  Підставляємо $T(n - 1) = T(n - 2) + 2^{n-1}$:
  $$T(n) = [T(n - 2) + 2^{n-1}] + 2^n = T(n - 2) + 2^{n-1} + 2^n$$

* **Крок 3:**  
  Підставляємо $T(n - 2) = T(n - 3) + 2^{n-2}$:
  $$T(n) = [T(n - 3) + 2^{n-2}] + 2^{n-1} + 2^n = T(n - 3) + 2^{n-2} + 2^{n-1} + 2^n$$

* **Крок $k$:**  
  Узагальнюючи на крок $k$ ($1 \le k \le n$):
  $$T(n) = T(n - k) + \sum_{j=0}^{k-1} 2^{n - j}$$

---

### Визначення умови завершення підстановки

Підстановка завершується при досягненні базового випадку $n - k = 0$, тобто при:
$$k = n$$

Тоді отримуємо:
$$T(n) = T(0) + \sum_{j=0}^{n-1} 2^{n - j}$$

Зробимо заміну індексу підсумовування $i = n - j$. Коли $j$ змінюється від $0$ до $n - 1$, новий індекс $i$ пробігає значення від $n$ до $1$:
$$\sum_{j=0}^{n-1} 2^{n-j} = \sum_{i=1}^n 2^i$$

Враховуючи, що за базовою умовою $T(0) = 1$, а число $1$ можна записати як $2^0$:
$$T(n) = 1 + \sum_{i=1}^n 2^i = 2^0 + \sum_{i=1}^n 2^i = \sum_{i=0}^n 2^i$$

---

### Обчислення суми геометричної прогресії

Отриманий вираз є сумою перших $(n + 1)$ членів геометричної прогресії з першим членом $b_0 = 2^0 = 1$ та знаменником $q = 2$:

$$\sum_{i=0}^n 2^i = \frac{b_0 (q^{n+1} - 1)}{q - 1} = \frac{1 \cdot (2^{n+1} - 1)}{2 - 1} = 2^{n+1} - 1$$

---

### Доведення методом математичної індукції

Перевіримо отриману формулу $T(n) = 2^{n+1} - 1$ за індукцією для всіх $n \ge 0$:

1. **База індукції ($n = 0$):**  
   $$T(0) = 2^{0+1} - 1 = 2^1 - 1 = 1$$  
   Співпадає з початковою умовою $T(0) = 1$. База виконується.

2. **Індукційний перехід ($n \to n + 1$):**  
   Припустимо, що для $n$ рівність виконується: $T(n) = 2^{n+1} - 1$.  
   Тоді для $n + 1$, згідно з рекурентним співвідношенням:
   $$T(n + 1) = T(n) + 2^{n+1} = (2^{n+1} - 1) + 2^{n+1} = 2 \cdot 2^{n+1} - 1 = 2^{(n+1)+1} - 1$$
   Індукційний перехід доведено.

---

### Підсумковий результат

Явний вигляд часу виконання програми для всіх цілих $n \ge 0$:

$$T(n) = 2^{n+1} - 1$$

* Перевірка для перших значень:
  * $T(0) = 2^1 - 1 = 1$
  * $T(1) = 2^2 - 1 = 3 \quad (1 + 2^1 = 3)$
  * $T(2) = 2^3 - 1 = 7 \quad (3 + 2^2 = 7)$
  * $T(3) = 2^4 - 1 = 15 \quad (7 + 2^3 = 15)$

**Асимптотична оцінка складності:** $\Theta(2^n)$ або $O(2^n)$ (експоненціальна складність / експоненціальний час виконання).
