> **Зауваження (з методички):**  
> *Для доведення співвідношення треба запропонувати алгоритм обчислення виразу, зазначеного у лівій частині рівності, що має вказану у правій частині рівності асимптотичну оцінку часу виконання програми.*

---

### Теоретичні засади (за підручником А. П. Креневича «Алгоритми і структури даних», 2021)

Згідно з методичним зауваженням, запис $\text{Вираз} = O(f(n))$ означає, що значення виразу можна обчислити за допомогою алгоритму, часова складність якого в найгіршому випадку не перевищує $O(f(n))$.

Ключовим принципом для побудови оптимальних алгоритмів обчислення сум і добутків є **динамічне накопичення (рекурентне обчислення доданків/множників)**:
* Якщо черговий доданок $a_i$ чи множник можна отримати з попереднього за $O(1)$ операцій (наприклад, $a^i = a \cdot a^{i-1}$, $i! = i \cdot (i-1)!$), то загальний час обчислення суми чи добутку з $n$ членів становить:
  $$\sum_{i=1}^n O(1) = O(n)$$
* Якщо ж для обчислення $i$-го члена потрібно виконати $O(i)$ або $O(m)$ операцій, то загальний час становить відповідно $O(n^2)$ або $O(nm)$.

## Пункт a): $\sum_{i=0}^n i = O(n)$

### Алгоритм:
```python
def compute_a(n):
    total = 0
    for i in range(n + 1):
        total += i
    return total
```

### Доведення:
1. Цикл `for i in range(n + 1)` виконує $n + 1$ ітерацій.
2. На кожній ітерації операція `total += i` виконується за сталий час $O(1)$.
3. Загальний час роботи алгоритму:
   $$T(n) = (n + 1) \times O(1) = O(n)$$
*(Примітка: за формулою $\frac{n(n+1)}{2}$ обчислення можливе навіть за $O(1)$, а оскільки $O(1) \subset O(n)$, співвідношення тим паче виконується).*

**Співвідношення доведено.**

## Пункт b): $\sum_{i=0}^n i^2 = O(n)$

### Алгоритм:
```python
def compute_b(n):
    total = 0
    for i in range(n + 1):
        total += i * i
    return total
```

### Доведення:
1. Цикл виконується $n + 1$ разів.
2. На кожній ітерації виконується множення `i * i` ($O(1)$) та додавання до суми ($O(1)$).
3. Тіло циклу вимагає $O(1)$ операцій.
4. Загальний час виконання:
   $$T(n) = (n + 1) \times O(1) = O(n)$$

**Співвідношення доведено.**

## Пункт c): $\sum_{i=0}^n a^i = O(n)$

### Алгоритм:
```python
def compute_c(a, n):
    total = 1.0  # при i = 0 доданок a^0 = 1
    power = 1.0  # поточне значення степеня a^i
    for i in range(1, n + 1):
        power *= a      # обчислення чергового степеня за 1 множення
        total += power  # додавання до суми
    return total
```

### Доведення:
1. Якщо обчислювати степінь $a^i$ «з нуля» на кожному кроці, алгоритм потребував би $O(n^2)$ або $O(n \log n)$ операцій.
2. Проте, використовуючи рекурентне співвідношення $a^i = a \cdot a^{i-1}$, кожний наступний степінь отримується з попереднього рівно за **одне множення**, тобто за $O(1)$ операцій.
3. Цикл робить $n$ ітерацій, кожна по $O(1)$ операцій:
   $$T(n) = O(1) + n \times O(1) = O(n)$$

**Співвідношення доведено.**

## Пункт d): $\sum_{i=0}^n i^i = O(n^2)$

### Алгоритм:
```python
def compute_d(n):
    total = 1  # 0^0 = 1
    for i in range(1, n + 1):
        power = 1
        for j in range(i):
            power *= i  # i множиться саме на себе i разів
        total += power
    return total
```

### Доведення:
1. Для кожного $i \in [1, n]$ обчислення значення $i^i$ за допомогою послідовного множення вимагає $i$ множень, тобто $O(i)$ елементарних операцій.
2. Додавання `total += power` виконується за $O(1)$.
3. Загальний час роботи програми:
   $$T(n) = \sum_{i=1}^n O(i) = O\left(\sum_{i=1}^n i\right) = O\left(\frac{n(n + 1)}{2}\right) = O(n^2)$$

**Співвідношення доведено.**

## Пункт e): $\prod_{i=1}^n \frac{1}{1 + i} = O(n)$

### Алгоритм:
```python
def compute_e(n):
    product = 1.0
    for i in range(1, n + 1):
        product *= 1.0 / (1.0 + i)
    return product
```

### Доведення:
1. Цикл виконується $n$ разів.
2. На кожній ітерації виконується додавання `1.0 + i`, ділення `1.0 / (...)` та множення `product *= ...`. Усі ці операції елементарні та виконуються за $O(1)$.
3. Загальний час роботи програми:
   $$T(n) = n \times O(1) = O(n)$$

**Співвідношення доведено.**

## Пункт f): $\prod_{i=1}^n \frac{1}{1 + i!} = O(n)$

### Алгоритм:
```python
def compute_f(n):
    product = 1.0
    fact = 1  # 0! = 1
    for i in range(1, n + 1):
        fact *= i                      # i! = i * (i-1)! обчислюється за O(1)
        product *= 1.0 / (1.0 + fact)  # множення на черговий дріб за O(1)
    return product
```

### Доведення:
1. Замість обчислення факторіалу $i!$ на кожній ітерації окремо (що дало б $O(n^2)$), ми використовуємо рекурентність факторіалу:
   $$i! = i \cdot (i - 1)!$$
2. На кожній ітерації факторіал оновлюється за 1 операцію множення.
3. Обчислення дробу та оновлення загального добутку також займає $O(1)$ операцій.
4. Цикл робить $n$ ітерацій, тому загальний час виконання:
   $$T(n) = n \times O(1) = O(n)$$

**Співвідношення доведено.**

## Пункт g): $\prod_{i=1}^n \frac{a^i}{1 + i!} = O(n)$

### Алгоритм:
```python
def compute_g(a, n):
    product = 1.0
    power = 1.0  # накопичувач степеня a^i
    fact = 1     # накопичувач факторіалу i!
    for i in range(1, n + 1):
        power *= a                     # a^i = a * a^(i-1) за O(1)
        fact *= i                      # i! = i * (i-1)! за O(1)
        product *= power / (1.0 + fact)# оновлення добутку за O(1)
    return product
```

### Доведення:
1. На кожному кроці $i$ одночасно підтримуються поточний степінь `power` ($a^i$) та поточний факторіал `fact` ($i!$).
2. Обидві величини перераховуються через попередні значення за $O(1)$ елементарних операцій:
   $$a^i = a \cdot a^{i-1}, \quad i! = i \cdot (i - 1)!$$
3. Ділення `power / (1.0 + fact)` та множення на `product` виконуються за $O(1)$.
4. Цикл виконується $n$ разів, отже:
   $$T(n) = n \times O(1) = O(n)$$

**Співвідношення доведено.**

## Пункт h): $\prod_{i=1}^n \frac{1}{1 + i^m} = O(nm)$

### Алгоритм:
```python
def compute_h(n, m):
    product = 1.0
    for i in range(1, n + 1):
        power = 1
        for j in range(m):
            power *= i  # обчислення i^m за m множень
        product *= 1.0 / (1.0 + power)
    return product
```

### Доведення:
1. Зовнішній цикл виконується $n$ разів (для $i = 1, 2, \dots, n$).
2. У внутрішньому циклі число $i$ множиться саме на себе $m$ разів для обчислення степеня $i^m$. Внутрішній цикл виконує рівно $m$ ітерацій, що вимагає $O(m)$ операцій.
3. Оновлення значення `product` займає $O(1)$ операцій на кожній ітерації зовнішнього циклу.
4. Загальний час роботи програми:
   $$T(n, m) = n \times (O(m) + O(1)) = O(nm)$$

**Співвідношення доведено.**

## Пункт i): $\prod_{i=1}^n \frac{1}{1 + i^i} = O(n^2)$

### Алгоритм:
```python
def compute_i(n):
    product = 1.0
    for i in range(1, n + 1):
        power = 1
        for j in range(i):
            power *= i  # обчислення i^i за i множень
        product *= 1.0 / (1.0 + power)
    return product
```

### Доведення:
1. Зовнішній цикл виконується для $i = 1, 2, \dots, n$.
2. Для кожного фіксованого $i$ внутрішній цикл обчислює степінь $i^i$ шляхом $i$ множень, тобто вимагає $O(i)$ елементарних операцій.
3. Оновлення значення `product` вимагає $O(1)$ операцій.
4. Загальний час роботи програми:
   $$T(n) = \sum_{i=1}^n (O(i) + O(1)) = O\left(\sum_{i=1}^n i\right) = O\left(\frac{n(n + 1)}{2}\right) = O(n^2)$$

**Співвідношення доведено.**
